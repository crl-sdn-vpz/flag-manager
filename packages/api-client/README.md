# api-client

Generated TypeScript client for the API. **Do not edit `src/generated/` or `openapi.json` by hand.**

- Regenerate after any route or schema change: `just gen-client` (from the repo root), then commit.
- `just check` fails if this package is stale.
- Imports: `api-client` (types + SDK functions), `api-client/query` (TanStack Query options),
  `api-client/client` (the configured fetch client).
